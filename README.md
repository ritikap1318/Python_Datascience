# Python_Datascience
A comprehensive repository tracking my journey and hands-on practice with foundational Data Science libraries: NumPy, Pandas, Matplotlib, and Seaborn. Core implementation of data manipulation, cleaning, and visualization techniques using Python's data science ecosystem.
## Objective
To master the core Python ecosystem for Data Science, focusing on data cleaning, preprocessing, and statistical visualization, acting as a stepping stone for advanced Machine Learning algorithms.
## Tech Stack 
**Numpy** : Mathematical computing and array operations.
## Repository Structure 
**01_Numpy**:Basic array creations, broadcasting, and matrix operations.
**02_Pandas_Series**:A collection of practical exercises focused on exploring, cleaning, and manipulating data with Pandas Series.
